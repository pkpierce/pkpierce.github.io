Family Board privacy policy

Last updated: September 21, 2026

Family Board is a private calendar display used by one household. This page explains what it does with Google account data.

What it accesses

With the account owner's permission, Family Board reads and writes events on the owner's Google Calendar so they can be shown on the home display and so events added on the display appear in Google Calendar.

Where the data goes

Calendar data is stored only on a computer inside the household. It is not sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Removing it stops all syncing, and the household's stored copy can be deleted from the home computer.
